# The Response Game — Brand System v13

## Brand hierarchy

**Master brand:** The Response Game  
**Game mode:** Resource Run  
**Descriptor:** Operational Simulation Platform

The acronym **TRG** is used as a clean wordmark. It is intentionally not a recreation of The Response Group corporate logo and does not use the rejected red-slash treatment.

## Brand promise

**Run the incident. Make the call. Watch what changes.**

The product should feel operational, credible, fast, and consequential. It should never look like a slide deck, LMS, government portal, or generic corporate dashboard.

## Visual language

- Near-black / deep-navy operating environment
- Muted blue-gray information layers
- Amber = active / selected / mission emphasis
- Cyan = information / situational awareness
- Green = successful deployment / verified state
- Red = actual operational consequence / warning only
- Inter typography with hierarchy created through weight, size, and tracking rather than novelty fonts
- 11–16px corner radii; no pill-box primary controls
- Fine operational borders rather than heavy card outlines
- Subtle map grids, contours, radar, and status layers only where they support atmosphere

## Logo / wordmark

The v13 TRG mark is deliberately simple:

- white TRG letters;
- no red slash;
- no surrounding pill or badge;
- thin amber baseline as the only brand accent;
- “THE RESPONSE GAME” used as the written master brand nearby when space allows.

`trg-mark.svg` is the application / manifest mark.

## Typography

Primary family: `Inter, system-ui, -apple-system, Segoe UI, sans-serif`.

Hierarchy:

- Display: 58–104px desktop / ~58px mobile landing
- Mission title: 42–72px
- Decision prompt: 21–36px
- Card headings: 14–24px
- Body: 13–18px
- Operational labels: 8–11px uppercase with tracking

## Presentation standard

Every screen must answer three questions quickly:

1. **What is happening?**
2. **What needs my attention now?**
3. **What changed because of what I did?**

If a visual element does not improve one of those answers, it should be removed or visually subordinated.
