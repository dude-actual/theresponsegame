# Known limitations

## Use boundary
This is a fictional single-device rehearsal, not an authenticated organizational pilot. Browser persona checks are not authorization; no secure multi-tenant/cloud backend, SSO/SCIM, private uploads, server entitlements, live messaging, queues or verified external callbacks are connected. The optional SQLite service remains legacy loopback development software and does not store the new pilot chain.

## Reliability and records
IndexedDB can be disabled, cleared or tampered with by the local user. Volatile fallback is visibly labeled. Active-time checkpoints can omit up to five seconds on abrupt process termination. Reopening offline is not guaranteed. Corrupt-state export is implemented; a trusted restore/import flow, automatic retention, legal hold, encrypted backup and cloud recovery are not. Pilot event capacity is bounded; do not treat synthetic benchmark results as production capacity.

History is append-only through normal application commands, not cryptographically authenticated. SHA-256 on export detects accidental change but is not a signature. Later review amendments/invalidations remain visible; a historical verification is not a permanent certification. No provider delivery state or external task success is fabricated.

## Content and assessment
Four authored initial experiences and two transfer conditions are review-required. Only escalation and resources have paired transfer retests. The situation and handover actions cannot legitimately verify through unrelated content. Lexical/structural repetition screening flags shared wording but does not perform full semantic validity review. Source assumptions are fictional, not governing operating procedures. Work completion, rule checks and evaluator-entered judgments are deliberately separate.

## Acceptance still required
No named independent practitioner, security specialist, accessibility user or real participant has accepted this release. Agent-driven controls/screenshots and automated tests do not substitute for those people. Whole-site WCAG conformance, screen-reader behavior, real-device behavior, actual learning/retention and professional rubric agreement remain open. Hosting/build evidence does not establish any of those claims.

See `BACKLOG.json` for priority, dependencies and acceptance criteria; do not create a second competing issue list here.
